# Countdown Timer

This repository contains a simple desktop countdown timer application built with
Python's `tkinter` module. The timer allows you to set hours, minutes and
seconds. When the countdown reaches zero it will beep and display a message.

## Requirements

Python 3 with the `tkinter` package installed (this is included with most
standard Python distributions).

## Usage

Run the timer with:

```bash
python timer.py
```

Fill in the desired time and press **Start**. A beep will sound when the time is
up.
